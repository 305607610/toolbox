# 叮当

叮当是一个 Windows 桌面工具合集。当前版本已实现十个工具：电子印章、PDF 转 HTML、PDF 工具箱、图片压缩、证件照、图片格式转换、图片处理、二维码、JSON 格式化、Base64 / URL 编解码。

## 技术栈

Tauri 2 + React 19 + TypeScript + Ant Design 6 + Lucide + Vite；PDF 转换与页面处理使用 PDFium（BSD-3-Clause），PDF 字体映射与解密使用 lopdf（MIT），二维码生成使用 qrcode（MIT），识别使用 jsQR（Apache-2.0）。

界面控件使用 Ant Design 的成熟实现。界面功能图标使用 Lucide；品牌、应用与安装图标使用 `public/app.png`。

## 名称与图标

- 显示名称：叮当

## 电子印章

- 公章：单位名称上弧、中心五角星、合同/财务专用章底部文字、编号；直径、边框、文字距边框、弧跨度、字号（自动/手动）、字距、星标大小与位置、底部文字字号/位置/字距均可调。编号默认沿下弧排列，可切换横排，并单独调距边框、弧跨度、字号、位置与字距。
- 个人章：方形或圆形，自动/竖排/双列布局，1–6 字，朱文/白文；文字距边框、字间距、字号（自动/手动）、整体左右/上下偏移、边框粗细均可调。
- 椭圆章：上弧、中间、下弧文字与编号；宽高、边框、上/下弧的文字距边框、弧跨度、字号与字距，中间文字的字号/位置/字距，编号的字号/位置/字距均可调。
- 签名：可手写（鼠标、触摸、手写笔，平滑度、笔宽、墨色、裁切留白可调，撤销/重做/清空），也可上传白纸上的签名照片或扫描件，自动估计纸张底色并把背景与阴影全部抠成透明，按去底阈值与边缘羽化保留笔迹、裁掉四周空白；笔迹可保留原色或统一墨色，本身已带透明通道的图片直接沿用。
- 右栏按对象分组：公章为「单位名称 / 章型与底部文字 / 编号 / 五角星 / 整体」，个人章为「姓名 / 版面 / 整体」，椭圆章为「整体 / 上弧 / 中间 / 下弧 / 编号」，签名分为「来源 / 笔迹（或图片笔迹）/ 导出」。每个对象的内容和几何在同一组里；数值都有数字输入与滑杆，字号可自动适配或手动指定，底部可恢复标准值。
- 文字溢出、字号超过布局、星标/底部文字/编号过近时给出提示并暂停导出；内置篆体缺字时列出字符、清空预览并禁用导出。
- 导出：透明或白底 PNG，300/600/1200 DPI，写入 pHYs 元数据；公章与椭圆章可另存 SVG。个人章与签名导出 PNG。
- 内置字体：敬峰中山王篆（SIL OFL 1.1）与崇羲小篆（CC BY-ND 3.0 TW）；另支持宋体、仿宋、楷体、黑体、隶书。
- 全部渲染在本地完成；导出的印章是设计稿，实际公章须按当地规定刻制备案。不提供国徽、机关模板或复刻现有印章的功能。
- 字体来源、授权与 SHA-256 见 `public/fonts/README.md`。

## 图片压缩

- JPG / PNG / WebP 批量压缩，可设目标体积、最大宽高、质量与输出格式。
- 逐张显示原始/压缩后体积与画质损耗，支持单张对比预览。
- 导出全部到指定文件夹，或逐张导出。

## 证件照

- 一寸、小一寸、大一寸、二寸、小二寸、大二寸六种照片规格，按 300 DPI 输出精确像素尺寸；规格内另设导出尺寸，可选标准 300 DPI 或原图分辨率（原尺寸），按当前构图使用源图像素（最高 3000 px 长边）。
- 导入照片后拖动、缩放构图，显示头顶与下巴辅助线；白底、蓝底、红底或原背景一键切换。
- 换底色在本地完成：从顶部与上侧取样背景色，只去除与画面边缘连通的相近区域，容差与羽化可调；无法识别时保留原图并提示。
- 6 寸相纸排版：按规格自动计算张数（4–12 张），居中排列并带裁切线。
- 导出 JPG/PNG，写入对应的 DPI 元数据：标准 300 DPI 或原图分辨率的有效 DPI；JPG 用 JFIF、PNG 用 pHYs，按毫米尺寸打印。原图分辨率（原尺寸）使用当前裁剪范围内的源图像素，裁得越紧可用像素越少；不足 300 DPI 时按 300 DPI 输出。
- 纯色背景、深色上衣的正面免冠照效果最好；与背景同色的衣物可能与背景一起被识别。

## PDF 转 HTML

- 单个 PDF 转成单个可离线打开的 HTML，页面尺寸与分页保持不变。
- 页面拆成真实元素：表格线、色块与曲线（含贝塞尔印章图形）是可缩放的 SVG 路径，并保留 PDF 的裁剪范围；文字按 PDF 字符坐标逐字定位，保留原始字号、颜色与字距，避免整体拉伸；内嵌字体会按 PDF 的 ToUnicode/CIDToGIDMap 重建 Unicode cmap、补齐浏览器需要的表后随文件携带；未内嵌的字体使用 PDFium 实际替换的字体家族。图片是独立 `<img>`，点击即可替换；图案、渐变、带裁剪的图片等无法拆分的复杂图形与无 Unicode 映射的符号按原样保留为底图或小图。
- 输出页自带「编辑文字 / 打印 / 保存副本」；修改后另存为新的单文件 HTML，按原毫米尺寸打印。
- 支持 144 / 192 / 300 DPI 与页面范围；加密 PDF 会请求密码。
- 使用 PDFium（BSD-3-Clause）做对象级提取，`pdfium.dll` 随应用打包；运行时不联网。

## 图片格式转换

- JPG、PNG、WebP、GIF、BMP、AVIF 批量转为 JPG、PNG 或 WebP，保持原尺寸与画面内容。
- 输出 JPG 可设置质量与透明区域背景色；PNG / WebP 保留透明背景。
- 逐张显示输出格式、尺寸与体积变化，支持单张或全部导出，文件名追加「_转换」。
- HEIC 暂不支持，会提示先转成 JPG 或 PNG。

## 图片处理

- 批量旋转 90° / 180° / 270°、水平或垂直翻转、按比例居中裁剪、按长边或百分比缩放。
- 文字水印：内容、字号（按图片宽度百分比）、颜色、九宫格位置、边距、粗体均可调。
- 输出格式可选自动 / JPG / PNG / WebP，可调质量；支持单张对比预览与批量导出。

## 二维码

- 生成文本 / 网址或 WiFi 二维码；尺寸、静区、纠错等级、前景色与背景色可调。
- 导出 PNG（按所选尺寸）或 SVG。
- 从图片、拖放或剪贴板识别二维码，支持网址、WiFi 与纯文本结果，可复制内容。

## JSON 格式化

- 格式化（2 空格 / 4 空格 / Tab）、压缩、校验、键名递归排序。
- 解析错误定位到行列；结果语法高亮，可切换自动换行。
- 支持打开 `.json`、复制、另存为 `.json`；Ctrl Enter 格式化，Ctrl S 保存。

## Base64 / URL 编解码

- Base64 文本编码 / 解码，按 UTF-8 处理，兼容 URL-safe 字符与缺失的 `=` 补位。
- 任意文件转 Base64 或 Data URL；粘贴 Base64 / Data URL 还原文件并保存。
- URL 组件或完整链接编码解码；查询参数自动解析为键值表，可复制单个参数值。

## PDF 工具箱

- 合并多个 PDF，可上移 / 下移调整顺序；提取、删除、旋转指定页面。
- 图片转 PDF：A4 或图片原尺寸，纵向 / 横向，页边距可调。
- 文字水印与图片盖章：内容或图片、字号或宽度、颜色、九宫格位置、边距、应用页码均可调。
- 移除密码：输入密码后另存为无密码副本。
- 页面级操作使用 PDFium，保留文字与矢量内容；加密 PDF 需先移除密码；全部本地完成。

## 设计

工作台采用 Windows 桌面工具类的惯例语言，以 uTools 的完成度为基准；不套装饰性视觉世界，把工艺放在对齐、间距、状态与速度里。

设计系统见 `DESIGN.md` 与 `.impeccable/design.json`；方向契约见 `.impeccable/surfaces/home.md` 与 `.impeccable/surfaces/seal.md`；产品事实见 `PRODUCT.md`。
