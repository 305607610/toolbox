# 叮当

叮当是一个 Windows 桌面工具合集。当前版本已实现电子印章工具，图片压缩工具仍为占位页。

## 技术栈

Tauri 2 + React 19 + TypeScript + Ant Design 6 + Lucide + Vite。

界面控件使用 Ant Design 的成熟实现。界面功能图标使用 Lucide；品牌、应用与安装图标使用 `public/app.png`。

## 名称与图标

- 显示名称：叮当
- 安装目录：`%LOCALAPPDATA%\Toolbox`；可执行文件 `toolbox.exe`
- 应用内 logo、窗口与任务栏图标、安装器与卸载器图标：`public/app.png`
- 工具功能图标：Lucide

## 运行

```bash
npm install
npm run tauri dev
```

浏览器里预览界面：

```bash
npm run dev
```

构建：

```bash
npm run build
npm run tauri build
```

## 电子印章

- 公章：单位名称上弧、中心五角星、合同/财务专用章底部文字、编号；直径、边框、文字距边框、弧跨度、字号（自动/手动）、字距、星标大小与位置、底部文字字号/位置/字距均可调。编号默认沿下弧排列，可切换横排，并单独调距边框、弧跨度、字号、位置与字距。
- 个人章：方形或圆形，自动/竖排/双列布局，1–6 字，朱文/白文；文字距边框、字间距、字号（自动/手动）、整体左右/上下偏移、边框粗细均可调。
- 椭圆章：上弧、中间、下弧文字与编号；宽高、边框、上/下弧的文字距边框、弧跨度、字号与字距，中间文字的字号/位置/字距，编号的字号/位置/字距均可调。
- 手写签名：鼠标、触摸、手写笔绘制，平滑度、笔宽、墨色、裁切留白可调，撤销/重做/清空。
- 右栏按对象分组：公章为「单位名称 / 章型与底部文字 / 编号 / 五角星 / 整体」，个人章为「姓名 / 版面 / 整体」，椭圆章为「整体 / 上弧 / 中间 / 下弧 / 编号」，签名是「笔迹 / 导出」。每个对象的内容和几何在同一组里；数值都有数字输入与滑杆，字号可自动适配或手动指定，底部可恢复标准值。
- 文字溢出、字号超过布局、星标/底部文字/编号过近时给出提示并暂停导出；内置篆体缺字时列出字符、清空预览并禁用导出。
- 导出：透明或白底 PNG，300/600/1200 DPI，写入 pHYs 元数据；公章与椭圆章可另存 SVG。个人章与签名导出 PNG。
- 内置字体：敬峰中山王篆（SIL OFL 1.1）与崇羲小篆（CC BY-ND 3.0 TW）；另支持宋体、仿宋、楷体、黑体、隶书。
- 全部渲染在本地完成；导出的印章是设计稿，实际公章须按当地规定刻制备案。不提供国徽、机关模板或复刻现有印章的功能。
- 字体来源、授权与 SHA-256 见 `public/fonts/README.md`。

## 已实现

- 无边框窗口与自绘顶栏：拖动、最小化、最大化、关闭
- 工具分组侧栏：全部工具、文书、图像，带数量
- 常驻搜索：Ctrl K 聚焦，跨全部工具匹配名称、说明与标签，回车打开第一个结果
- 浅色默认，深色切换，选择在本地保存
- 两列工具卡片，含悬停、键盘焦点与「打开」动作
- 电子印章工具：四种模式、实时预览、PNG/SVG 导出与原生保存对话框
- 图片压缩占位页；Escape 返回
- 空搜索、空分组、未知工具的状态

## 目录

- `src/pages/Home.tsx`：工作台首页、搜索与分组过滤
- `src/pages/SealTool.tsx`：电子印章工作区、模式切换与导出
- `src/pages/ToolPage.tsx`：图片压缩占位页
- `src/seal/`：印章几何、SVG/Canvas 渲染、字体、导出、签名与保存
- `src/components/`：自绘顶栏、侧栏、工具卡片
- `src/tools.ts`：工具与分组的产品内容
- `src/styles/global.css`：布局、主题变量与视觉细节
- `src/styles/seal.css`：印章工作区布局
- `src/styles/fonts.css`：内置字体声明
- `src-tauri/`：Tauri 外壳、窗口配置、dialog 插件与图标
- `public/app.png`：应用图标；`src-tauri/icons` 由它生成并携带来源信息
- `public/fonts/`：两款内置篆体、授权文件与来源说明
- `scripts/generate-font-coverage.py`：从字体 cmap 生成缺字检查数据

## 设计

工作台采用 Windows 桌面工具类的惯例语言，以 uTools 的完成度为基准；不套装饰性视觉世界，把工艺放在对齐、间距、状态与速度里。

设计系统见 `DESIGN.md` 与 `.impeccable/design.json`；方向契约见 `.impeccable/surfaces/home.md` 与 `.impeccable/surfaces/seal.md`；产品事实见 `PRODUCT.md`。
